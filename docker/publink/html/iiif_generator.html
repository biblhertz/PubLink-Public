▶ How to set up GitHub Pages and create a token
Step 1 — Create a repository
  1. Sign in to github.com.
  2. Click + → New repository. Give it a name like iiif-manifests.
  3. Set visibility to Public, check Add a README file, click Create repository.
Step 2 — Enable GitHub Pages
  1. In your repository, open Settings → Pages (left sidebar).
  2. Under Source, choose Deploy from a branch, select branch main, folder / (root). Click Save.
  3. Your manifests will be served at https://username.github.io/iiif-manifests/.
Step 3 — Create a Personal Access Token
  1. Click your profile avatar → Settings → Developer settings → Personal access tokens → Tokens (classic).
  2. Click Generate new token (classic). Give it a name (e.g. IIIF Generator) and set an expiry.
  3. Under Select scopes, check repo only. Click Generate token.
  4. Copy the token immediately — GitHub only shows it once. Paste it in the field above.
Step 4 — Fill in the form
Enter the token, your repository as username/iiif-manifests, and leave Branch as main.

The token is stored only in your browser's localStorage. It leaves your computer solely to authenticate GitHub API requests made from this page.
