# Schema Sources

The Dataverse archival snapshot of this repository omits `docker/publink/xsd/` —
standard, publicly maintained schema files, not part of PubLink itself. They
can be obtained from their official sources:

## JATS Journal Publishing (versions 1.0-1.4)
https://jats.nlm.nih.gov/publishing/<version>/
e.g. https://jats.nlm.nih.gov/publishing/1.4/

## OJS Native XML / Import-Export schema (versions 3.3, 3.4, 3.5)
https://github.com/pkp/ojs/tree/main/plugins/importexport/native
(native.xsd, pkp-native.xsd, importexport.xsd — see the matching release tag
for each OJS version, e.g. ojs-3_4_0)
